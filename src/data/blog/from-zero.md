## 背景

我一直想有一个自己的网站。不是那种模板博客，也不是社交媒体主页——而是一个真正属于我自己的数字空间。

## 过程

买了域名 catstarry.xyz，用了 AI 做需求分析，从 6 月聊到 7 月，把一个模糊的想法变成了清晰的 7 个板块。

下面是一段用来记录构建命令的代码：

```bash
npm run build
```

![一颗属于 Blog 的暖色星球](/blog/digital-space.svg)

| 阶段 | 留下的东西 |
| --- | --- |
| 想法 | 一张不会消失的草稿 |
| 实现 | 一个能被阅读的页面 |

如果你也在开始自己的空间，可以从 [Astro 文档](https://docs.astro.build/) 读起。

## 结果

现在你看到的这个博客，就是第一块拼图。

后续还有：聚合首页、碎碎念时间线、编程学习笔记、项目展示、和一个只有两个人能看到的财务面板。
