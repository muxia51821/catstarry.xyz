女王宫给我的困难，并不只是名字太多。9月30日的记录里，我已经做过大量准备，开始留意山墙、门楣和说明牌；但到10月2日，我仍明确说，自己对这里的许多故事有些迷茫。

原因之一是，同一座寺没有按一部史诗从头排到尾。人物看起来熟悉，邻近的画面却可能来自另一组文本。认识罗波那，未必懂得他为什么出现在湿婆的山下；认识黑天，也还要区分杀刚沙与火烧森林。

这篇以已读的女王宫研究材料为起点，展开四幅藏经阁山墙，再接到猴王兄弟与舞王湿婆。故事的说明、学者对图像的解释、本人现场的辨认分开保留。两部史诗与泰国表演的关系，见 [[thailand-cambodia-epic-connections|从两部史诗到曼谷与吴哥]]。

## 先把故事放回建筑构件

山墙 pediment 沿屋顶轮廓展开，门楣 lintel 是门洞上方的横向构件；门框立柱 door jamb 又可能承载铭文。故事可以在这些位置出现，但不能把每块叙事雕刻都叫作门楣。

假门 false door 又提出一个不同问题：有门的形式，是否就能从那里进入？Glaize的装饰章节将这类石雕门面联系到实际木门的两扇、闭合与门闩形式。[\[11\]](#source-11) 它保留“门”的视觉语言，却不是供身体穿越的通道。看见类似门框，仍要区分真实开口与封闭表面；这也是9月30日崩密列问答中结构与装饰的一个连接。

建筑构件会改变故事怎样被看见。横向门楣适合沿宽度安排人物，沿屋顶轮廓展开的山墙可以分出上下层；层叠可以组织动作与神圣空间，却不使所有上层人物自动比下层身份更高。撼山的上下关系须从正在发生的故事解释，不能一条规则包办全部题材。材料与叠涩结构的比较，已接回 [[angkor-history-questions|历史主篇的建筑段]]。

研究阅读器已经按两座惯称“藏经阁”的建筑列出四幅山墙。下表是文献定位，不是本人照片已经全部完成匹配的清单。“东面／西面”指山墙朝向，需要先辨建筑南北，再辨其两端。

| 构件位置 | 题材与人物关系 |
| --- | --- |
| 南阁东山墙 | **罗波那撼凯拉萨山**：山下用力的罗波那，与山顶的湿婆、乌玛。 |
| 南阁西山墙 | **迦摩扰动湿婆冥想**：弓箭、欲望与苦修；随后第三眼焚毁迦摩。 |
| 北阁东山墙 | **坎达瓦森林焚烧**：因陀罗降雨，黑天与阿周那帮助火神，森林生命受难。 |
| 北阁西山墙 | **黑天杀刚沙**：预言、受迫害的孩子、归来与统治者的死亡。 |

北阁东山墙的题材有识别史：Glaize早期导览采用“因陀罗之雨”的讲法；Ly Boreth在2005年论文中采用森林焚烧识别，并在161页注12说明此前的不同认定。本文沿用阅读器与后者的识别，保留这个差异。[\[1\]](#source-1)[\[2\]](#source-2) 看到“骑象的因陀罗和雨”是有用的线索，完整题材仍要结合其余人物与动作。

## 罗波那撼山：极大的力量，遇到极小的动作

罗波那是《罗摩衍那》中劫走悉多、与罗摩交战的统治者。撼山故事却让他进入湿婆的神圣居所 Kailāsa，凯拉萨山。这种人物交会，使史诗角色与湿婆叙事发生联系；不能单凭出现了罗波那，就把画面认作楞伽战争。

故事的关键动作是罗波那试图撼动山体。湿婆与配偶乌玛／帕尔瓦蒂在上方；罗波那在下方，以巨大的力量扰动整个居所。湿婆只需压住山，便使他无法继续。随后赞颂、苦修与获得恩惠的叙事，让力量的冲撞转向臣服与神恩。前因及具体过程随版本变化，本文不指定一个覆盖所有传统的动机。

这幕最清楚的对比，是下面用力、上面控制。多头、多臂可以把下方的力量扩展开；上下层的距离又使山顶与山下处在不同的位置。神的强大不必依靠比对方更激烈的动作来表现，而可以通过几乎不动来表现。这是根据故事与已读构图说明作出的阅读归纳。

罗波那作为敌人和作为湿婆崇拜者的两面，也值得一起保留。某一故事里的对立身份，没有取消他在另一故事里的虔信。Ly进一步讨论这个画面与湿婆传统的联系；把具体地方图像唯一追溯到某一文本，仍属于需要论证的解释。[\[2\]](#source-2)

凯拉萨是湿婆的居所，Meru／须弥山首先承担宇宙中心的意义；搅乳海的轴山通常叫Mandara／曼陀罗山。三者都能以“山”表现神圣空间，不能因此直接互换。Mandara与Meru在东南亚象征中的叠合，另见 [[angkor-mandara-meru|搅乳海与须弥山专题]]。

## 迦摩射箭：苦修与世界的生成怎样相遇

南阁另一面转到冥想中的湿婆。迦摩 Kāma 是爱神，以弓箭扰动他的专注，促使他与帕尔瓦蒂结合。湿婆第三眼的火焚毁迦摩。这些环节在已读阅读器中已经展开；后续迦摩以何种方式继续存在，则有版本差异。

这段之所以比“爱神射了一个人”更复杂，在于目标是退出欲望、专注苦修的湿婆。推动结合的故事，又把他拉回配偶、后代与世界的生成。苦修者与家主都属于湿婆的形象，使克制、欲望、毁灭与生成在同一位神身上相遇。

湿婆为什么退入冥想，诸神又为什么要把他带回来？Met对一幅1890年印度版画的说明，采用了一个有明确前因的讲法：湿婆因妻子萨蒂之死而退居森林，世界失去他的引导，诸神安排帕尔瓦蒂接近他，迦摩则试图让他注意她。迦摩被焚以后，湿婆最终认出帕尔瓦蒂是萨蒂的转生，秩序才得以恢复。[\[10\]](#source-10) 爱神的行动由此接到失去配偶、退出世界与重新参与世界的过程。这里借馆方介绍的一种叙事补充关系，不据此断定女王宫采用完全相同的版本。

与撼山的一面放在一起，区别更清楚：一边让他在神圣居所与配偶相伴，一边让他抵抗扰动冥想的欲望。Ly用图像配对解释这种并置；这是研究者对组织方式的解读，不是碑铭给出的逐幅创作说明。[\[2\]](#source-2)

读图时，冥想者与射箭者首先建立冲突。第三眼焚毁迦摩属于补齐的叙事，不能要求一幅雕刻把所有前因、动作和后续都显式表现出来。若画面中的某个属性或人物已经残损，故事知识能够帮助提出判断，却不能补成石面上实际仍有的细节。

名字也要放回这里：乌玛通常是帕尔瓦蒂的名称；萨蒂与帕尔瓦蒂在上述叙事中有前生与转生的关系；悉多则是罗摩的妻子。Satī／萨蒂、Sītā／悉多与Śiva／湿婆的转写容易相近，角色关系却不同。本文的撼山和冥想场景都不需要把悉多放到湿婆身边。10月1日，导游曾把受辱自焚者称为乌玛，当天整理已提醒应区别萨蒂与后续的帕尔瓦蒂／乌玛；达刹祭祀的完整情节和版本仍没有在本文核定。

## 焚林的起点：火神为什么要吃掉一座森林

北阁东面的故事进入《摩诃婆罗多》。阿耆尼是火神。Ganguli英译初篇CCXXV节把他的困境讲得很具体：长期吞食祭祀酥油以后，他失去活力，需要通过吞噬森林及其中生命恢复力量。但每次尝试，都受到因陀罗降雨的阻挡。[\[3\]](#source-3)

因陀罗保护森林，原因也不是笼统的“雨天然反对火”。蛇王德叉迦是他的朋友，住处与家属、其他森林生命都受到保护。火神因此求助黑天和阿周那，请他们阻止雨水，也阻止生命逃离。[\[3\]](#source-3)

这样，这场冲突的阵营可以列清楚：

| 行动者 | 此刻的目标与关系 |
| --- | --- |
| 阿耆尼 | 吞噬森林，恢复自身力量；求助黑天与阿周那。 |
| 因陀罗 | 用雨保护森林和朋友德叉迦一方；阿周那又是他的儿子。 |
| 黑天与阿周那 | 帮助火神，阻雨并围堵逃离者；并非只与某一只蛇作战。 |
| 森林中的生命 | 试图脱离火与围堵；它们的受难也是这段叙事的内容。 |

父亲与儿子站在不同阵营，使亲属关系无法单独解释行动。火神有自己的需要，雨神有自己的保护关系，英雄承接了求助。这里有多个动机，没有一条“神都站在同一边”的简单规则。

## 箭、雨与逃亡者：焚林为什么不能只读成胜利

阿周那以武器阻住雨，也使林中生命难以逃离。文本写到蛇、鸟、兽及其他存在被围堵、杀伤；在这组事件里，黑天和阿周那的强大与受难者的处境同时存在。[\[4\]](#source-4)[\[5\]](#source-5)

因此，看这一幕时，注意力不宜只停在上方的因陀罗和英雄。下部生命承受了这些动作的后果。神与英雄之间的冲突，是叙事的一面；被燃烧、被阻止逃离的世界，是另一面。将它归纳为水与火的对抗可以帮助看构图，却没有穷尽伦理内容。

还有两个会改变故事理解的细节。第一，德叉迦本人当时不在森林，不能把这段概括成“黑天当场烧死蛇王”。他的儿子和家属涉及逃离，因陀罗的保护也继续发生作用。[\[4\]](#source-4) 第二，阿修罗摩耶向阿周那请求庇护，阿周那答应，黑天与火神便没有杀他。[\[5\]](#source-5)

英雄可以参与大范围毁灭，又能对一个求助者作出保护承诺。这种张力不必由编辑替读者消掉。“强大的英雄”与“毫无问题的行动”并不是同一个判断。

这一幕还帮助区分阿周那与罗摩。两者都可能持弓，但要认定是谁，还需看他的伙伴、对手及此次动作。在焚林里，黑天、因陀罗、雨与森林共同提供关系；孤立的弓，不能完成身份判断。

## 黑天杀刚沙：同一个黑天，换了一段生平

北阁西面的高潮，是黑天 Kṛṣṇa 制服并杀死刚沙 Kaṃsa。故事回到黑天自己的成长：刚沙获知妹妹提婆吉 Devakī 的第八个孩子会导致自己的死亡，于是囚禁她、迫害孩子；黑天被保护、在牧人家庭成长，后来返回马图拉，终结刚沙的统治。这一因果沿用原阅读器；预言、婴儿转移与杀刚沙的环节，又以《薄伽梵往世书》的具体段落核对。[\[9\]](#source-9)

预言没有自动使刚沙死亡。正是他为阻止预言而实施的暴政，持续制造危机；孩子幸存，才使后来的归来成为可能。因此高潮背后有预言、恐惧、迫害、保护与反击，不能只保留画面里的一个杀人动作。

建筑场景也参与叙事：楼阁和人物所在的位置，使这次冲突处于统治者的空间中。把它与北阁东面的森林场景并看，能够发现同一个黑天进入了不同关系：一边帮助火神并与阿周那合作，一边面对迫害自己的统治者。

两段并置没有让它们成为同一天连续发生的事件。黑天生平还跨越《诃利世系》与往世书等叙述；仅因他也出现在《摩诃婆罗多》，不能把所有黑天故事都标成这部史诗的同一章节。

黑天与罗摩同为毗湿奴的化身，提供了神学上的连接；但黑天杀刚沙，没有变成罗摩救悉多的异名。人物关系和具体事件仍要各自保留。

## 猴王兄弟：一处争斗怎样接到楞伽战争

9月30日我拍到的现场说明牌，明确列出 Vālin and Sugrīva。前者本文称婆利，后者称须羯哩婆。说明牌提供了题材线索，尚没有把我拍到的每块构件都对应到文献中的某个位置。

故事里，兄弟失和，须羯哩婆失去王位。寻找悉多的罗摩与他结盟，帮助他对抗婆利；恢复王位后，他组织盟友帮助罗摩。哈努曼是这组盟友的重要人物，却不是兄弟争斗中的第三位猴王。

这段从内部王位冲突接到对外战争。王位恢复与寻找悉多相互支持，使“猴军替罗摩行动”有了政治与亲属关系，而不只是动物军队服从英雄的奇观。

婆利被射杀，又引发对罗摩行动的质问。《罗摩衍那》猴国篇留有婆利与罗摩的辩论；争论包括没有正面交战的射杀、统治者的惩罚权以及对盟友的承诺。[\[6\]](#source-6)[\[7\]](#source-7) 完整解释见 [[thailand-cambodia-epic-connections|史诗与表演主篇]]。

认出两个猴形人物仍不等于分清每一个。文献讨论的题材可以帮我读故事，照片中的指认则还需要动作、相对位置和构件记录。女王宫动物头守护者也不因此全部成为哈努曼。

## 舞王湿婆：同一位神为什么又静又动

研究阅读器还把女王宫的跳舞湿婆，与南阁的冥想湿婆联系起来。这个联系的意义，是让“湿婆的形象”从一个固定姿态变成几种相关的表达：可以专注不动，可以压制撼山者，也可以舞动。

Nāṭarāja／舞王的解释，将运动与宇宙生成、毁灭和循环联系起来。跳舞因而具有神圣意义；它与冥想共同表现的，是神的不同状态，而非两个互不相干的人物。

作为比较，Met所藏的一件南印度朱罗铜合金舞王像，具有火圈、鼓、火焰和脚下矮人等配置；馆方说明分别解释了这些属性。[\[8\]](#source-8) 高棉石刻中的舞动形象，仍应按作品实际属性描述；没有看见的火圈或持物，不应由另一件作品自动补上。

这一处也是“学过以后仍要回到对象”的例子。知识能够使我知道舞蹈的意义，却不能把一种著名造像的完整清单放进另一件作品。具体高棉图像与典型南印度配置的异同，值得在找到对应原图以后继续展开。

## 四幅山墙没有排成一部连续电影

把这几段展开后，女王宫的并置就有内容了：罗波那遇到湿婆，迦摩扰动冥想，黑天与阿周那帮助焚林，黑天又制服刚沙；另一些构件接到猴王兄弟及其他故事。

Ly Boreth提出以“图像配对”理解部分叙事的组织：画面之间可以互补，也可以对照；这套解释有明确取样范围，并非每个角落都严格遵守一套规则。[\[2\]](#source-2) 本文借它提出观看关系，不将它写成已经查明的唯一设计方案。

在这个基础上，我可以比较几个具体问题：力量为什么有时表现为用力，有时表现为不动；英雄的行动为什么既恢复秩序，也可能带来伤害；同一个人物换了伙伴和对手以后，故事为什么改变。这样的比较来自几段故事之间的关系，不需要把它们改写成连续年表。

女王宫的供奉中心与建筑史，见 [[angkor-history-questions|吴哥历史主篇]]。宗教奉献、叙事选择和图像编排能够共同参与建筑的意义，也各需要相应证据。

## 已学内容与仍需回看的对象

目前已经可以说明四山墙的故事关系、猴王联盟，以及湿婆几种状态之间的对照。没有完成的是本人照片与建筑朝向的逐件匹配。本文因此不插入尚未确认的女王宫图片，也不以通用插图代替现场证据。

原日结还记录了说明牌中的 Hayagrīva 杀 Madhu 与 Kaitabha、悉多被劫、黑天与阿修罗交战、伐楼拿和因陀罗等题材。这些线索没有被删成“无用背景”，但目前不根据题名替它们补出具体面板的完整故事。尤其“悉多被劫”的劫持者，原记录保留识别分歧；FC37还单列崩密列所谓悉多火焰试炼的对象缺口，不能借女王宫题名一起放行。

10月2日讨论的Kala上下构图、方位守护神及其与主神的叠加，现由 [[angkor-guardians-images|方位、门口与造像专题]]完整展开。本人照片中是哪位神、构件朝向和上下人物关系，仍按FC65逐件核对。“因陀罗出现在上方”尚不足以判定所有人物的神学等级。概念说明与具体照片鉴定不必等待同一组证据。

我在现场认出一些，也仍有迷茫。把故事展开，使迷茫有了具体位置：可能是不熟悉文本，可能是不懂同一人物的另一面，也可能是照片与构件还没对上。三种缺口需要不同的补法，不应被一个“已经学会”覆盖。
