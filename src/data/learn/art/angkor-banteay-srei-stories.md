女王宫两座藏经阁的四幅山墙，雕着湿婆、罗波那、黑天与阿周那等人物。他们的故事来自不同文本；这篇先交代撼山、冥想、焚林与杀刚沙的前因和行动，再讨论相邻画面为什么会被学者放在一起比较。

9月30日到女王宫前，我读过一些山墙故事，现场也看了门楣和说明牌。两天后在博物馆，我仍说：“女王宫很多时候我有点迷茫。”

女王宫没有按一部史诗从头排到尾。人物看起来熟悉，邻近的画面却可能来自另一组文本。认识罗波那，未必懂得他为什么出现在湿婆的山下；认识黑天，也还要区分杀刚沙与火烧森林。

猴王兄弟和舞王湿婆又出现在其他构件上。两部史诗与泰国表演的关系，见 [[thailand-cambodia-epic-connections|从两部史诗到曼谷与吴哥]]。

## 先把故事放回建筑构件

山墙pediment沿屋顶轮廓展开，门楣lintel是门洞上方的横向构件；门框立柱door jamb又可能承载铭文。叙事雕刻会出现在这些不同构件上。

假门false door是封闭的石雕门面。Maurice Glaize的考古导览《吴哥古迹》将它的形式联系到实际木门的两扇、闭合与门闩。[\[11\]](#source-11) 它模仿木门的外形，墙体却仍封闭。

横向门楣可以沿宽度排列人物，山墙则能把山体、动物和人物分成上下层。撼山题材中，湿婆在山顶，罗波那在山下用力；其他题材的上下关系未必相同。建筑材料与叠涩结构，见 [[angkor-history-questions|历史主篇]]。

Glaize的导览与艺术史学者Ly Boreth的研究，按两座惯称“藏经阁”的建筑定位四幅山墙。“东面／西面”指山墙朝向，两座建筑本身又分南北。

| 构件位置 | 题材与人物关系 |
| --- | --- |
| 南阁东山墙 | **罗波那撼凯拉萨山**：山下用力的罗波那，与山顶的湿婆、乌玛。 |
| 南阁西山墙 | **迦摩扰动湿婆冥想**：弓箭、欲望与苦修；随后第三眼焚毁迦摩。 |
| 北阁东山墙 | **坎达瓦森林焚烧**：因陀罗降雨，黑天与阿周那帮助火神，森林生命受难。 |
| 北阁西山墙 | **黑天杀刚沙**：预言、受迫害的孩子、归来与统治者的死亡。 |

北阁东山墙的题材有识别史：Glaize早期导览采用“因陀罗之雨”的讲法；Ly Boreth在2005年论文中采用森林焚烧识别，并在161页注12说明此前的不同认定。[\[1\]](#source-1)[\[2\]](#source-2) 上表采用Ly的识别。骑象的因陀罗和雨能提供线索，题材仍要结合其余人物与动作判断。

## 罗波那撼山：湿婆怎样压住山下的挑战者

![女王宫撼山山墙，上方湿婆与配偶，下方多头多臂人物托举层叠山体，周围排列动物与人物。](/learn/travel-knowledge/A001603.jpg)

*女王宫南藏经阁东山墙，2026年9月30日。山下的多头多臂罗波那向上用力，湿婆与乌玛在山顶；中间的层叠山体把两组人物接成一次撼山行动。[\[1\]](#source-1)[\[2\]](#source-2)*

罗波那是《罗摩衍那》中的统治者，劫走了悉多，又与罗摩交战。撼山故事却让他进入湿婆的神圣居所 Kailāsa，凯拉萨山。这里表现的是他与湿婆的相遇，而非楞伽战争。

故事的关键动作是罗波那试图撼动山体。湿婆与配偶乌玛／帕尔瓦蒂在上方；罗波那在下方，以巨大的力量扰动整个居所。湿婆只需压住山，便使他无法继续。随后罗波那赞颂、苦修，获得恩惠。撼山的前因及具体过程随版本变化。

下方罗波那的多头、多臂表现用力，上方湿婆几乎不动便能压住山。两者的动作差异，让撼山者的力量与湿婆的控制形成对比。

罗波那既是罗摩的敌人，也能在另一个故事中成为湿婆的崇拜者。Ly讨论了撼山画面与湿婆传统的联系，具体地方图像源于哪个文本版本，仍有解释空间。[\[2\]](#source-2)

凯拉萨是湿婆的居所，Meru／须弥山首先承担宇宙中心的意义；搅乳海的轴山通常叫Mandara／曼陀罗山。三者都以“山”表现神圣空间，在故事中的角色却不同。Mandara与Meru在东南亚象征中的叠合，另见 [[angkor-mandara-meru|搅乳海与须弥山专题]]。

## 迦摩射箭：湿婆为什么焚毁爱神

南阁另一面转到冥想中的湿婆。迦摩 Kāma 是爱神，以弓箭扰动他的专注，促使他与帕尔瓦蒂结合。湿婆第三眼的火焚毁迦摩。迦摩后来以何种方式继续存在，各版本有差异。

湿婆为什么退入冥想，诸神又为什么要把他带回来？纽约大都会艺术博物馆（简称Met）对一幅1890年印度版画的说明，采用了一个有明确前因的讲法：湿婆因妻子萨蒂之死而退居森林，世界失去他的引导，诸神安排帕尔瓦蒂接近他，迦摩则试图让他注意她。迦摩被焚以后，湿婆最终认出帕尔瓦蒂是萨蒂的转生，秩序才得以恢复。[\[10\]](#source-10) 这是理解故事前因的一个版本；女王宫图像采用的具体文本版本仍不明确。

与撼山的一面放在一起，区别更清楚：一边让他在神圣居所与配偶相伴，一边让他抵抗扰动冥想的欲望。Ly用“图像配对”解释这种并置。[\[2\]](#source-2)

乌玛通常是帕尔瓦蒂的名称；萨蒂与帕尔瓦蒂在上述叙事中有前生与转生的关系；悉多则是罗摩的妻子。Satī／萨蒂、Sītā／悉多与Śiva／湿婆的转写容易相近，角色关系却不同。10月1日，导游曾把受辱自焚者称为乌玛；我后来查到的叙述，则区分萨蒂与帕尔瓦蒂／乌玛。当天讲法出自哪个版本，仍不清楚。

## 焚林的起点：火神为什么要吃掉一座森林

北阁东面的故事进入《摩诃婆罗多》。阿耆尼是火神。这里采用译者Kisari Mohan Ganguli的英译本，初篇第225节（CCXXV）把他的困境讲得很具体：长期吞食祭祀酥油以后，他失去活力，需要通过吞噬森林及其中生命恢复力量。但每次尝试，都受到因陀罗降雨的阻挡。[\[3\]](#source-3)

因陀罗用雨保护森林，是因为蛇王德叉迦是他的朋友。德叉迦的住处与家属，以及林中其他生命，都受到保护。火神因此求助黑天和阿周那，请他们阻止雨水，也阻止生命逃离。[\[3\]](#source-3)

| 行动者 | 此刻的目标与关系 |
| --- | --- |
| 阿耆尼 | 吞噬森林，恢复自身力量；求助黑天与阿周那。 |
| 因陀罗 | 用雨保护森林和朋友德叉迦一方；阿周那又是他的儿子。 |
| 黑天与阿周那 | 帮助火神，阻雨并围堵逃离者；并非只与某一只蛇作战。 |
| 森林中的生命 | 试图脱离火与围堵；它们的受难也是这段叙事的内容。 |

阿周那虽然是因陀罗的儿子，此时却答应帮助火神。父亲试图保住朋友的森林，儿子以武器阻挡父亲的雨。

## 箭、雨与逃亡者：焚林中的受难

![女王宫焚林题材山墙：上方骑象人物与雨线，下方森林、动物和战车。](/learn/travel-knowledge/A001609.jpg)

*女王宫山墙，2026年9月30日。上方的骑象人物与雨线、下方的森林、动物和战车，对应Ly Boreth所讨论的坎达瓦焚林题材。[\[2\]](#source-2)*

照片上方是骑象的因陀罗与雨线，下方有树木与动物，还能看到车轮和持弓人物。焚林的受难者也被雕在山墙上。

阿周那以武器阻住雨，也使林中生命难以逃离。文本写到蛇、鸟、兽及其他存在被围堵、杀伤；在这组事件里，黑天和阿周那的强大与受难者的处境同时存在。[\[4\]](#source-4)[\[5\]](#source-5)

德叉迦本人当时不在森林，他的儿子和家属涉及逃离，因陀罗的保护也继续发生作用。[\[4\]](#source-4) 阿修罗摩耶向阿周那请求庇护，阿周那答应，黑天与火神便没有杀他。[\[5\]](#source-5)

阿周那阻止森林生命逃离，却又答应保护摩耶。救下一个求助者，并没有消除这场焚烧对其他生命的伤害。

阿周那与罗摩都持弓，伙伴和场景却不同。这里黑天与因陀罗同在画面中，结合雨和森林，指向坎达瓦焚林。

## 黑天杀刚沙：同一个黑天，换了一段生平

北阁西面的高潮，是黑天 Kṛṣṇa 制服并杀死刚沙 Kaṃsa。故事回到黑天的成长：刚沙获知妹妹提婆吉 Devakī 的第八个孩子会导致自己的死亡，于是囚禁她、迫害孩子；黑天被保护、在牧人家庭成长，后来返回马图拉，终结刚沙的统治。预言、婴儿转移与杀刚沙的环节，可见于《薄伽梵往世书》的相应段落。[\[9\]](#source-9)

北阁西面以楼阁和人物的位置表现宫廷中的冲突，东面则是森林、雨与焚烧。两面都有黑天，他的伙伴、对手与行动却不同。

杀刚沙与焚林发生在黑天生平的不同阶段。关于他的故事还见于《诃利世系》和往世书等文本；两幅雕刻因人物而联系起来，情节则来自不同段落。

## 猴王兄弟：一处争斗怎样接到楞伽战争

9月30日我拍到的现场说明牌，明确列出 Vālin and Sugrīva，即婆利与须羯哩婆这对猴王兄弟。

![女王宫山墙上的猴形人物争斗，右侧另有持弓人物。](/learn/travel-knowledge/A001605.jpg)

*女王宫，2026年9月30日。中部两名猴形人物交手，右侧另有持弓人物，与婆利、须羯哩婆及罗摩的故事配置相符。我仍分不清哪位是婆利，哪位是须羯哩婆。*

故事里，兄弟失和，须羯哩婆失去王位。寻找悉多的罗摩与他结盟，帮助他对抗婆利；恢复王位后，他组织盟友帮助罗摩。哈奴曼是这组盟友的重要人物，却不是兄弟争斗中的第三位猴王。

婆利被射杀，又引发对罗摩行动的质问。《罗摩衍那》猴国篇留有婆利与罗摩的辩论；争论包括没有正面交战的射杀、统治者的惩罚权以及对盟友的承诺。[\[6\]](#source-6)[\[7\]](#source-7) 完整解释见 [[thailand-cambodia-epic-connections|史诗与表演主篇]]。

## 舞王湿婆与冥想中的湿婆

女王宫既有跳舞的湿婆，也有冥想中的湿婆和压制撼山者的湿婆。同一位神，在几处雕刻中采取了不同姿态。

Nāṭarāja／舞王的解释，将运动与宇宙生成、毁灭和循环联系起来。女王宫把湿婆的舞动与冥想雕在不同位置。

南印度朱罗时期的舞王像提供了另一种配置。Met收藏的一件铜合金像，有火圈、鼓、火焰和脚下矮人，馆方逐项解释了这些属性。[\[8\]](#source-8) 女王宫的舞王则雕在高棉石构上，采用不同的材料与构图。

## 四幅山墙的配对与对照

Ly Boreth提出以“图像配对”理解部分叙事的组织：画面之间可以互补，也可以对照。她的研究把若干相邻题材放在一起，讨论它们怎样围绕同一位神的不同动作展开。[\[2\]](#source-2)

撼山与冥想两面，都表现湿婆对扰动的回应：罗波那以力撼山，迦摩以箭扰动欲望。北阁两面则有黑天的不同战斗：一面与阿周那焚林，一面杀死刚沙。这些画面可以对照，并不按故事发生的先后连成一条年表。

女王宫的供奉中心与建筑史，见 [[angkor-history-questions|吴哥历史主篇]]。

## 尚未认清的几处雕刻

现场说明牌还列出马头形态的Hayagrīva杀死Madhu与Kaitabha两名阿修罗、悉多被劫、黑天与阿修罗交战，以及水神伐楼拿和骑象的因陀罗等题材。有些雕刻我仍分不清，其中“悉多被劫”一幕的劫持者也有识别分歧。

在崩密列，曾被解释为“悉多火焰试炼”的画面也没有确定。
