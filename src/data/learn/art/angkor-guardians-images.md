吴哥建筑与博物馆中的形象，有的守护方向，有的守护入口，有的承载主神，还有的参与故事。多臂、冠饰或某种手势，可能出现在不同人物身上。这篇从位置、持物、坐骑和动作，讨论几组在旅行中引起疑问的造像。

10月2日在吴哥国家博物馆，我问了门口守护者与叠层门楣，还问了水神、合体神和手掌姿势。认识名字之后，站到具体造像前，我仍会认错。

有时疑问出在位置：同一位因陀罗为什么既能在故事里降雨，又能出现在建筑的东方？有时出在外形：多臂、冠饰、柔和的面貌，究竟能把谁认出来？还有一次，我质疑了仅凭双掌向前与身形就判断女性身份的说法。

## 八方位神与门口守护者

八方位神，通常称 aṣṭadikpāla：四个正方向加四个斜方向，由不同神祇守护。守护某个方向，是这些神祇的一种职能；他们也会在故事和其他构件上出现。

| 方向 | 通行配置与辨认线索 |
| --- | --- |
| 东 | 因陀罗 Indra；象、金刚杵 |
| 东南 | 阿耆尼 Agni；火焰、山羊 |
| 南 | 阎摩 Yama；水牛、杖 |
| 西南 | 尼利提 Nirṛti；坐骑与形象在不同传统中有变化 |
| 西 | 伐楼拿 Varuṇa；水、绳索，常联系摩羯鱼 makara |
| 西北 | 风神 Vāyu；鹿、飘动的衣带 |
| 北 | 库毗罗 Kubera；财富属性，坐骑并非处处相同 |
| 东北 | 伊舍那 Īśāna，湿婆的一个形态；牛、三叉戟 |

这张表列的是通行的八方向配置，不是某座吴哥寺院的雕像清单。研究印度雕刻的学者Vinay Kumar Gupta，对印度Narayani Mata寺的研究提供了一个比较：西南尼利提在该处骑驴，西面的伐楼拿骑鹅，北面的库毗罗骑羊。地方传统会改变坐骑，也会改变辨认时可用的线索。[\[1\]](#source-1)

门口的Dvārapāla则按入口职能得名：dvāra是门，pāla是守护者。法国图卢兹的Georges-Labit博物馆记录了一件吴哥时期的砂岩像，将它归为门口守护者。[\[2\]](#source-2) 守住进入圣所的边界，与维护宇宙方向，是两种空间关系。它们可以出现在同一建筑中，却不必是同一套人物。

武器和威严的姿态可以使雕像看起来像守卫；门口的位置有助于判断守门职能；要认出某个方向的守护神，还要看朝向、持物与坐骑。

## 因陀罗与伐楼拿：同一神有不止一种职能

因陀罗在方向表中守东，在坎达瓦焚林故事中又降雨保护森林。他降雨保护森林，是因为与蛇王德叉迦的关系。阿周那是他的儿子，却帮助火神焚林。[[thailand-cambodia-epic-connections|史诗与表演篇]]继续展开这场冲突。

伐楼拿与水相连，也担任西方守护者。水神属性与方位职能可以出现在同一形象中。我10月2日问过的那件对象，所在构件和朝向还不清楚。

## 门楣叠层：谁是主角，谁是坐骑，谁构成边界

![女王宫雕刻，中央小型人物与象形坐骑位于兽面上方，四周展开卷草。](/learn/travel-knowledge/A001600.jpg)

*女王宫，2026年9月30日。中央小型人物坐在象形坐骑上，下方的大口兽面与两侧卷草相接。*

我在博物馆问过门楣上几个上下叠放的形象：它们都是神吗？纽约大都会艺术博物馆（简称Met）收藏的一件11世纪后半叶门楣，题名区分了毗湿奴、其坐骑迦楼罗，以及下方的Kala兽面。[\[3\]](#source-3) 其中一位是主神，一位是坐骑，兽面又有另一种作用。

在这件门楣上，迦楼罗承载毗湿奴，Kala位于下方。Maurice Glaize编写的考古导览《吴哥古迹》介绍了这种装饰：Kala兽面在门楣中央，两侧装饰从口中展开。[\[4\]](#source-4) 兽面与坐骑虽然相邻，承担的构图作用不同。

这件馆藏用来比较三层形象的关系：上方人物的持物、迦楼罗的鸟形与下方兽面，共同帮助辨认。上图女王宫雕刻的中层则是象形坐骑，配置不同。

狮子、那伽等形象也可能守护入口、承托人物或参与故事，具体作用随着人物关系与构件位置而改变。

## 多臂、冠饰与持物：毗湿奴和观音

在博物馆里，多臂与王者般的冠饰会使不同人物看起来相近。毗湿奴与某些菩萨形象都可能有这种外观，具体身份还要看持物与头饰。

柬埔寨国家博物馆的一件6世纪毗湿奴像，馆方用轮、海螺和杖等持物描述它；其中一些部分已经缺损。[\[5\]](#source-5) 残损的手可能原来握着持物，今天看不见，并不表示它本来没有。

观音Avalokiteśvara／Lokeśvara的辨认也需要具体属性。Met记录的一件观音来自柬埔寨，呈自在坐姿；头饰中的阿弥陀佛像是身份线索；这件造像2023年已经归还柬埔寨。[\[6\]](#source-6) 馆方提出，这件造像还可能兼有王室肖像意图。

[[angkor-history-questions|历史篇]]介绍了以佛教尊格奉献父母的碑文记载。10月2日问过的那件拼合像，其身份与制作方式仍未确定。

## 双掌向前，并不表示女性身份

当天曾以双掌姿势、圆润身体或柔和面貌猜测造像为女性，我对此提出了质疑。

Met的一件泰国加冠立佛，两手向前，馆方同时讨论无畏与说法手势的指部变化；美国沃尔特斯艺术博物馆（Walters）所藏另一件立佛也用双手无畏姿势，并把它联系到泰国后来的“阻止海洋”姿态命名。[\[7\]](#source-7)[\[8\]](#source-8) 两件佛像都使用双掌向前的姿势，手势表达的是宗教意义。

手印mudrā指手部姿态及其宗教意义；一个地区的佛传姿态名称，还可能连接整尊造像与某个故事。手指是否相接，掌心是否向外，另一只手在做什么，都是辨认线索。

那尊引起争论的像，我能确认的仍只是“加冠”“双掌朝前”等外形，身份尚不清楚。

## 烦恼、轮回与解脱

10月2日，我还问了kilesa（烦恼）、saṃsāra（轮回）与涅槃，讨论由造像转到了佛教教义。

当天讨论把贪、嗔、痴作为理解烦恼的入口。《正见经》英译把三者列为不善的根，随后解释苦、苦的起因、止息与道路。[\[11\]](#source-11) 因而“烦恼”在这里不只指一时心情不好，也涉及行动怎样被推动，执取怎样继续发生。

《缘起分别经》进一步把苦的发生写成有条件的过程：渴爱引出执取，执取又成为“有”的条件，再接到生、老与死。渴爱包括对色、声、香、味等经验的欲求；执取包括对感官欲乐、见解和自我学说等的抓取；“有”在这里是bhava，译本用becoming，指存在与生成的过程。[\[12\]](#source-12)

同一经文也沿这些关系说明止息：渴爱止息，执取及其后续条件随之止息。轮回讨论的是生死与苦如何继续发生；涅槃关注的则是苦及其条件的止息。[[angkor-mandara-meru|搅乳海篇]]中的甘露使饮用者不死，成为双方争夺的物品；佛教在这里讨论的解脱，关心的是使苦持续发生的条件怎样止息。

## Harihara：湿婆与毗湿奴的合体像

Harihara通常译作诃利诃罗，把毗湿奴Hari与湿婆Hara结合。美国诺顿·西蒙博物馆（Norton Simon）收藏的一件早期雕像，馆方按身体两侧的差异解释这一复合形象：湿婆一侧有发髻与半只第三眼，毗湿奴一侧有冠饰与海螺。[\[9\]](#source-9) 同一个身体的两侧，分别保留两位神的特征。

诃利诃罗结合的是两位神，与梵天不同，也与梵天、毗湿奴、湿婆并列为三神的概念不同。

Harihara把两位神的特征组合在一具身体中；罗摩与黑天则被视为毗湿奴的化身。国王或祖先以神圣形象接受奉献，又涉及纪念与祭祀，三者所说的神人关系各不相同。

## 林伽与约尼：浇淋与导流

林伽 liṅga 与约尼 yoni 并不是人形。林伽联系湿婆，约尼联系女性生成力量；它们既有身体与生成的象征，也以具体器物配置参与供奉。

亚洲艺术收藏机构Casa Asia收藏的一组高棉林伽、约尼与基座，馆方说明了浇淋与导流：液体经过林伽、汇入基座，再从出口流出。[\[10\]](#source-10) 林伽、基座与出口共同组成供奉时使用的装置。

只按性器官解释林伽与约尼，会遗漏湿婆崇拜和圣所中的祭祀；完全忽略身体象征，又难以说明它们的生成含义。

这组馆藏呈现了浇淋与导流的结构。我当时还问过“活的”是什么意思，这涉及遗迹所在的空间是否还在使用、是否仍进行供奉。

那伽在 [[angkor-mandara-meru|搅乳海篇]]中作为绕山的绳索，[[angkor-banteay-srei-stories|女王宫故事篇]]则有神祇、坐骑与故事人物的上下安排。

博物馆里几件引起疑问的叠层门楣、拼合像和加冠造像，仍没有认清身份。位置、持物和手势让我有了辨认线索，但那尊双掌向前的像表现谁，拼合像又为什么会被联系到国王，仍是具体的问题。
