10月2日在吴哥国家博物馆，我说还想补“神的方位”和不熟悉的《摩诃婆罗多》。当天还问了门口守护者、叠层门楣、水神、合体神和手掌姿势。一路认识了不少名字，到了具体造像前，名字却常常不够用。

有时疑问出在位置：同一位因陀罗为什么既能在故事里降雨，又能出现在建筑的东方？有时出在外形：多臂、冠饰、柔和的面貌，究竟能把谁认出来？还有一次，双掌向前与身形引出的女性判断受到了我的质疑。这里保留这些问题，把原研究和事后核对接成几种不同的关系；博物馆里尚未匹配题名的对象仍不补身份。

## 守方向与守门，回答的是不同问题

八方位神，通常称 aṣṭadikpāla：四个正方向加四个斜方向，由不同神祇守护。方向使神祇获得一种空间职能。它不是按八个神各自的全部生平分类，也不意味着他们只能在那个方向出现。

| 方向 | 通行配置与辨认线索 |
| --- | --- |
| 东 | 因陀罗 Indra；象、金刚杵 |
| 东南 | 阿耆尼 Agni；火焰、山羊 |
| 南 | 阎摩 Yama；水牛、杖 |
| 西南 | 尼利提 Nirṛti；坐骑与形象在不同传统中有变化 |
| 西 | 伐楼拿 Varuṇa；水、绳索，常联系摩羯鱼 makara |
| 西北 | 风神 Vāyu；鹿、飘动的衣带 |
| 北 | 库毗罗 Kubera；财富属性，坐骑并非处处相同 |
| 东北 | 伊舍那 Īśāna，湿婆的一个形态；牛、三叉戟 |

这张表是原研究中八方向的整理，不是吴哥每座建筑的现场配置表。Gupta对印度Narayani Mata寺雕刻的研究提供一个很有用的比较：西南尼利提在该处骑驴，西面的伐楼拿骑鹅，北面的库毗罗骑羊。研究者正是把位置、属性与其他实例一起使用，才作出身份解释。可见，通行坐骑是线索，不能把地方变体一概判成“刻错了”。[\[1\]](#source-1)

门口的 Dvārapāla 则按入口职能得名：dvāra是门，pāla是守护者。图卢兹Georges-Labit博物馆所记的一件吴哥时期砂岩像，就是按门口守护者分类。[\[2\]](#source-2) 守住进入圣所的边界，与维护宇宙方向，是两种空间关系。它们可以出现在同一建筑中，却不必是同一套人物。

因此，“这像守卫”可以先描述姿态；要说“这是门口守护者”，还需要构件与位置；要进一步说“这是某个方向的某位神”，需要朝向与属性共同支持。现在没有逐件配齐的照片，不能让表格代替这几步。

## 因陀罗与伐楼拿：同一神有不止一种职能

因陀罗在方向表中守东，在坎达瓦焚林故事中又降雨保护森林。后一段的行动来自与蛇王德叉迦的关系，不是因为“东边必须下雨”。阿周那是他的儿子，却帮助火神焚林。方向职能、亲缘身份、当次行动，分别说明了不同的事情；[[thailand-cambodia-epic-connections|史诗与表演篇]]继续展开这场冲突。

伐楼拿也不能只缩成“西方那一位”。与水相连的神祇属性，能够进入故事或造像；成为西方守护者，又把他安置到一套空间秩序中。10月2日材料保留了Varuṇa的线索，但具体对象的构件与朝向仍受FC65限定。不能先猜某块山墙朝西，再用方向表给它命名。

“身份—职能—行动”并读以后，神话与建筑才容易接起来。名字能相同，参与的关系可以变化。这也是为什么读故事不能只拿一张神名表，读建筑也不能只拿一张人物亲属表。

## 门楣叠层：谁是主角，谁是坐骑，谁构成边界

我问过的叠层门楣，最容易把几种关系混成“上面又是另一个神”。Met记录的一件11世纪后半叶门楣，题名明确区分毗湿奴、其坐骑迦楼罗，以及下方的Kala头。[\[3\]](#source-3) 三个形象没有被当成三位身份相同的主神。

迦楼罗在这里承载毗湿奴，回答的是主神与坐骑怎样配置。Kala的大口或面部则参与门楣的构图。Glaize的早期建筑说明把Kala置于门楣中央、联系从口中展开的装饰；这给它在建筑中的位置一个可读的解释。[\[4\]](#source-4) 三层相邻，并没有把Kala变成迦楼罗，也没有把迦楼罗变成毗湿奴的另一副面孔。

这件馆藏只是一个有明确题名的比较对象，不是我在博物馆问的那块门楣。回到自己的照片，还要核对主神的属性、鸟形、下方形象及实际构件。若对象残损，只能记录尚存的关系，不能按完整图式补出缺掉的手、武器或人物。

同样，狮子、那伽与其他动物形象可以守护、承托、装饰或参与故事。角色要由它正在做什么、放在哪里来解释。单凭“在门附近”不能把所有动物都叫Dvārapāla，单凭嘴很大也不能把所有兽面都叫同一种神。

## 多臂与冠饰给出线索，持物才继续缩小范围

在博物馆里，多臂与王者般的冠饰会使不同人物看起来相近。毗湿奴与某些菩萨形象都可能有这种外观。手臂数能说明形象的表达方式，却不是一个足够的姓名。

柬埔寨国家博物馆的一件6世纪毗湿奴像，馆方用轮、海螺和杖等持物描述它；其中一些部分已经缺损。[\[5\]](#source-5) 用这种对象读法，残手首先是证据损失，不能直接算作“这个神原来没有此属性”。持物、冠饰、躯干与出土地的信息，要合在一起看。

观音 Avalokiteśvara／Lokeśvara 的辨认也需要具体属性。Met所记录的一件柬埔寨自在坐观音，头饰中的阿弥陀佛像是身份线索；这件造像2023年已经归还柬埔寨。[\[6\]](#source-6) 馆方还提出它可能兼有王室肖像意图，但“可能”仍是解释性质，不能顺势把所有菩萨都命名为某位国王。

这也使历史篇里的奉献关系更清楚：碑铭把父母与神圣形象关联，和靠某件残像的脸推断“这就是国王的父亲”，需要不同证据。[[angkor-history-questions|吴哥历史主篇]]的父母奉献已经有文字依据；10月2日具体拼合像的身份与制作问题，仍没有因此全部解决。

## 双掌向前：一次判断为什么应当撤回

当天材料留下过以双掌姿势、圆润身体或柔和面貌判断性别的过程，我也提出质疑。与其把最后一个猜测写成答案，不如保留这次判断是怎样失去依据的。

Met的一件泰国加冠立佛，两手向前，馆方同时讨论无畏与说法手势的指部变化；Walters所藏另一件立佛也用双手无畏姿势，并把它联系到泰国后来的“阻止海洋”姿态命名。[\[7\]](#source-7)[\[8\]](#source-8) 这两件有馆藏记录的佛像，足以说明双掌向前不是女性身份的证明。

手印 mudrā 讨论手部姿态和意义；一个地区的佛传姿态名称，还可能连接整尊造像与某个故事。两类解释有关联，却不应看见一只手就直接补出全部佛传。手指是否相接、掌心是否向外、另一只手在做什么，都可能影响解释；照片没有显示的细节，不靠名词补齐。

因此，具体对象目前最稳妥的描述仍可以是“加冠”“双掌朝前”“某部分缺损”。描述不等于没有理解：它说明哪些细节已经看到，哪些身份判断仍待题名与完整形象支持。FC64、FC66继续保留这一层未知。

## 佛像之外：烦恼、轮回与解脱的区别

10月2日还讨论了kilesa、saṃsāra与涅槃。它们使观看越过“佛像是哪一种样式”，进入供奉和修行所指向的问题。烦恼不是造像身上的属性，轮回也不是一个需要从冠饰中认出的神。

原讨论以贪、嗔、痴理解烦恼的一组核心。《正见经》英译把三者列为不善的根，随后解释苦、苦的起因、止息与道路。[\[11\]](#source-11) 因而“烦恼”在这里不只指一时心情不好，也涉及行动怎样被推动，执取怎样继续发生。

《缘起分别经》则将渴爱、执取、有、生及老死放进有条件的关系，又说明相关条件止息时的止息。[\[12\]](#source-12) 轮回与解脱的讨论由此不同于“神赐予永生”的神话。[[angkor-mandara-meru|搅乳海篇]]里的甘露使不死成为争夺对象；这里的涅槃关注苦及其条件的止息。两种叙述都涉及死亡与超越，目标和因果却不同。

这不是本篇已经解释完整佛教义理，更不是现场一尊佛像能证明我掌握了这些概念。它补回了材料里的一条连接：辨认造像可以帮助知道面对谁，供奉者所理解的苦、行动与解脱，则不能只由雕刻风格代答。

## Harihara：结合两位神，不能顺手扩成三位

Harihara把毗湿奴Hari与湿婆Hara结合。Norton Simon的一件早期雕像，馆方按身体两侧的差异解释这一复合形象。[\[9\]](#source-9) 辨认的重点是两边怎样分别保留神祇特征，而不是只看见“有几张脸”就计数。

这与梵天不同，也与把梵天、毗湿奴、湿婆并列为三神的概念不同。一件合体像可以证明某种结合被制作出来；若要解释为什么制作、怎样供奉、与哪个赞助群体有关，仍须对象和场所的资料。它不能独自证明整个社会实行了某种现代意义的宽容政策。

合体关系也不同于化身关系。罗摩、黑天接到毗湿奴，是神学谱系；Harihara把两种神的特征组合在同一身体中；一位君主或祖先以神圣形象接受奉献，则又涉及纪念与祭祀。把这三种连接分开，人物关系图才能避免一根箭头包办所有解释。

## 林伽与约尼：从非人形象征到供奉的动作

原研究里的林伽 liṅga 与约尼 yoni 问答，改变了“神像必须长成人的样子”的预设。林伽联系湿婆，约尼联系女性生成力量；它们既有身体与生成的象征，也以具体器物配置参与供奉。

Casa Asia收藏的一组高棉林伽、约尼与基座，馆方说明了浇淋与导流：液体经过林伽、汇入基座，再从出口流出。[\[10\]](#source-10) 这个说明让符号成为一组可使用的关系。看林伽不只问它像什么，还要问它放在哪里，液体怎样经过，身体怎样参与仪式。

因此，将它只翻成性器官，会丢掉神祇、圣所与祭祀的关联；将它完全抽象化，又会丢掉身体和物质。非人形不等于没有形象，象征也不等于只有观念。雕刻的石头、承接的基座、流动的液体，共同使供奉有了动作。

这里核到的是一组馆藏的解释，不是所有带槽石块都可被认成约尼。我原先对“活的”所提的问题，若指活人在特定场所怎样参与、某种仪式今天是否持续，仍须具体语境。这一未知不能用标准器物说明代答。

## 把几种关系重新接回这趟旅行

门口守护者使“进入”成为问题，方位神使建筑进入空间秩序，主神与坐骑表现承载关系，林伽与基座让供奉有了物质路径。它们可以共同组成一座寺院，而不是互相争夺一个唯一神名。

在 [[angkor-mandara-meru|搅乳海篇]]，那伽还作为绕山的绳索；在 [[angkor-banteay-srei-stories|女王宫故事篇]]，坐骑、人物与建筑部位共同进入叙事。现在这篇补的是关系层：同一个名字在不同情境中做什么，不同形象为什么会在同一构件上相邻。

尚未完成的是逐件照片匹配：八方向是否完整出现、某构件实际朝哪边、叠层门楣究竟是哪件、博物馆拼合像与手印的题名。正文解释了可成立的概念，不把这些未决对象写成已认对。也没有把事后查到的馆藏解释，反写成当日已经懂了的现场见闻。
