# catstarry.xyz

`catstarry.xyz` 是木下的个人网站，记录文章、足迹、学习内容及项目。

## 主要模块

- Home：星图式站点入口
- Blog：文章与阅读体验
- Feed：公开足迹、碎碎念与剪藏
- Learn：学习内容
- Projects：项目展示

## 技术栈

Astro + React (shadcn/ui) + Cloudflare Pages / Workers + D1 + KV + R2。
